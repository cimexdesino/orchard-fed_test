# React + TypeScript + Vite

This project uses the following:

- Styling Tailwind - Good combination with react since we create reusable ui components
- Framer motion for ui transitions
- React aria - For ui library to confirm to accessibility standards. For the purpose of this exam I didn't add any ui/headless ui library
- Eslint + prettier - Formatting/Linting

Considerations

- Section heights are determined by content, alternatively we could set fixed heights at breakpoints to show ellipsis instead

## Setup

To get started, follow these steps:

- Clone the repo
- Run npm install
- Run npm run dev
